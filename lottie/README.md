# Lottie drop-in slots

Export JSON (or regenerate with `node scripts/build-logo-lotties.mjs`) and place files here. The site uses SVG/CSS fallbacks until a file loads successfully.

## Logo pack (shipped)

Generated by `scripts/build-logo-lotties.mjs` from the nav hug mark (outer arcs + inner Cs, `#12181b`).

| File | Artboard | Duration | Loop | Used on |
|------|----------|----------|------|---------|
| `logo.json` | 400×400 | hug idle from frame 70 | on hover | Nav brand mark |
| `logo-name.json` | 920×300 | ~6s (frame 360), then hold | no | Home hero (`#name-hero`) |
| `logo-fun.json` | 400×400 | ~4s | yes | Optional nav swap (not wired) |

**Motion notes**

1. **`logo.json`** — same dual-C hug mark (solid black); rests fully drawn; soft squeeze idle plays on nav hover only.
2. **`logo-name.json`** — same draw-in, centered; outer arcs break out to bookend the full name and stay (no fade) while Cs become the leading letters of **Cillian** / **Cooke**; trailing letters cascade in (Syne); calm full-name hold.
3. **`logo-fun.json`** — same mark with a playful orbit/sway idle.

Regenerate after timing tweaks:

```bash
node scripts/build-logo-lotties.mjs
```

## Behaviour

- Player: `lottie-web` via CDN (`js/lottie.js`)
- `prefers-reduced-motion`: keeps SVG fallback, skips autoplay
- Slots: `data-lottie="lottie/….json"`; home uses `data-loop="false"`
- Nav mark: `data-play="hover"` — rests on the full mark (`data-hold-frame`), animates only while hovered/focused
- `CillianLottie.replay('#name-hero')` reloads the home animation when returning to home
